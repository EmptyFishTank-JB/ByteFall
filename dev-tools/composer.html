COMPOSER

Make and mix generated songs from the game's own code. Nothing here is saved to the game; your library stays in this browser until you export it. The official tracks open in the MIXER.

THE SONG

A song's code (ByteFall's own format, the same one the MUSIC PLAYER's ENTER SONG CODE takes) is what you give me to reproduce it exactly.

Build sets how far the layers have come in (the game raises it through a track); a layer solo plays just that layer.

THE NOTES

The notes fall to the keys as they're played, and a key lights while its note sounds. Muted or unsoloed instruments are dimmed; BUILD and the layer solo change which notes are there.

INSTRUMENTS

LIBRARY
